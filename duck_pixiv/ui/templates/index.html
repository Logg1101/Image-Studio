Pixiv Account / Authentication Settings

Configure which Pixiv account is used for uploads. By default, it runs in safe Dry Run Mode (simulates uploads without sending real network requests).

Found in your browser when logged into pixiv.net (Application → Cookies → PHPSESSID).

How to get your PHPSESSID in 15 seconds (Works 100%)
  1. In Chrome or Edge, go to pixiv.net and make sure you are logged in.
  2. Press F12 (or right click → Inspect) to open Developer Tools.
  3. Click the Application tab at the top (if hidden, click the >> arrows).
  4. In the left sidebar, expand Storage → Cookies and click https://www.pixiv.net.
  5. Find the row named PHPSESSID and double-click its Value to copy it.
  6. Paste that value into the box above and click Save Changes. That's it!

Stored locally in data/settings.json. Never hardcoded or sent to third parties.

How do I get my Pixiv Refresh Token?

Pixiv uses OAuth PKCE authentication. You can obtain your refresh_token safely using either method below:

Method 1: One-Click Helper (Easiest)

Run the helper batch file included in duck_pixiv\:

duck_pixiv\get_pixiv_token.bat

It opens the official Pixiv login page in your browser. Once you log in, your refresh_token is printed right in the terminal window to copy.

Method 2: Web Browser DevTools (No Extra Tools)
  1. Open Chrome/Edge in Incognito and open DevTools (F12 → Network tab).
  2. Log in to pixiv.net.
  3. In the Network filter, type auth/token or callback.
  4. Look for the JSON response containing "refresh_token": "..." and paste it here.
